# 🧮 Calculadora de Tabuada

Aplicação web simples desenvolvida com **HTML, CSS e JavaScript puro**, com foco em manipulação do DOM e interação dinâmica com o usuário.

## 🎯 Objetivo

Este projeto foi desenvolvido para praticar conceitos fundamentais do desenvolvimento front-end, especialmente:

- Manipulação de elementos com JavaScript
- Eventos de formulário
- Renderização dinâmica de conteúdo na interface
- Estruturação de layout com HTML e CSS

## ⚙️ Funcionalidades

- Geração automática de tabuada a partir de um número informado
- Definição do limite da multiplicação
- Atualização dinâmica da interface sem recarregar a página
- Validação simples de entrada de dados

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
